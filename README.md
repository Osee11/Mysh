# mySH - Mini Shell in C
<!--English -->
A mini bash-like shell built from scratch in C.
Features: fork/exec, signal handling (SIGINT, SIGCHLD), builtins (cd, exit, echo)
run: make run
Tech: C, Linux syscalls, process management

<!--Français-->
Un mini shell de type bash créé de zéro en C.
Fonctionnalités : fork/exec, gestion des signaux (SIGINT, SIGCHLD), commandes intégrées (cd, exit, echo)
Exécution : make run
Technologies : C, appels système Linux, gestion des processus
